# 数据库 AI 应用

让思源数据库拥有可配置的 AI 自动化能力。

![功能预览](preview.png)

## 功能

- 在数据库右上角增加 `AI 应用` 入口。
- 内容总结：压缩长文本，生成简洁摘要。
- 自定义 AI：选择当前数据库中的任意一个或多个字段，按自定义要求逐行处理。
- 智能分类：根据候选分类自动归类。
- 智能提取：提取姓名、电话、标签等结构化信息。
- 公式计算：使用类 Excel 公式自动补全数字列。
- 整列处理：预览前 3 行后，一次性写回整列。
- AI 模型配置会保存到思源插件数据中，重启后自动恢复。

## 模型支持

插件默认连接本机 Ollama，也支持：

- 本机模型：Ollama、LM Studio。
- 主流 API：OpenAI、DeepSeek、Kimi、智谱 GLM、阿里云百炼、Google Gemini、Anthropic Claude。
- 聚合服务：硅基流动、OpenRouter。
- 自定义第三方 API：可填写协议、Base URL、API Key 和模型名称。

远程请求通过思源内核代理转发，以避免浏览器跨域问题。使用第三方 API 时，勾选的数据库内容会发送到对应服务商。API Key 仅保存在当前思源客户端。

## 公式示例

```text
={单价}*{数量}
ROUND(AVG({语文},{数学}), 1)
SUM({收入},-{支出})
```

支持 `SUM`、`AVG`、`MIN`、`MAX`、`ROUND`、`ABS`、`COUNT`、`POW`、`SQRT`。

## 使用方法

1. 在思源中打开一个包含数据库的文档。
2. 点击数据库右上角的 `AI 应用`。
3. 在 `AI 模型设置` 中选择本地模型或第三方 API。
4. 选择应用类型、输入字段和输出字段。
5. 先预览，再执行 `整列应用`。

## 说明

思源数据库字段类型由内核管理，第三方插件无法注册新的原生字段类型。本插件会使用数据库内的文本或数字字段保存结果，并在数据库界面中提供带 `AI` 标记的应用入口。
